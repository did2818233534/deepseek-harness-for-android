# 使用指南

## 聊天与联网

在模型设置中选择 DeepSeek 模型。聊天快捷设置可以调整模型、思考强度和联网搜索。启用搜索后，模型根据任务决定是否检索；付费推理及联网服务使用自己的 API Key。任务进行时可继续输入要求，引导会在下一步生效。长按消息可多选、复制 Markdown、导出或分享；点开消息可全屏阅读和复制渲染后的文字。

图片可从相册或文件管理器添加。在不支持图片输入的模型上，默认临时切换到支持图片的模型，完成后恢复；可在模型设置里关闭。关闭后图片仍可作为文件交给工具。完整版可按指定坐标或尺寸处理图片。

## 工作区与归档

外部文件导入后以副本存放。生成的文件可点回复中的链接打开，或导出到自己选择的位置。文件库支持多选删除，只作用于应用内副本。设置中可关闭删除对话时自动清理关联文件的选项。

归档会在后台保存会话与文件映射。聊天记录、文本等优先无损压缩，图片、音视频、PDF 和 DOCX 默认原样存放。校验并持久化成功后才清理副本；其他对话仍引用的文件保留。恢复遇到同名新文件时另存并更新链接。

## 完整版工具

首次需要时解开内置 Python 和 Pillow，之后可按需下载受支持的包。用户安装的包随覆盖升级保留，卸载会清除该版的私有数据。执行器处理模型提交的文件任务，支持的包受手机架构、安装脚本和执行权限约束。

## 个性化

在「设置 → 个性化」填写回答语言、格式或背景信息。编辑会自动保存，从后续消息起生效，清空即可取消。
